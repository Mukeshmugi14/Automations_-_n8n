# AutoReel Studio – Content Creation Automation Agent

Automation to generate short video scripts/thumbnails and auto-post YouTube Shorts.

> Note: Actual video rendering can be done via a separate service or manual step. This workflow focuses on script + metadata generation and scheduling uploads.

## Features

- Takes topics or source text
- Generates short-form script with hook, body, CTA
- Generates title, description, tags
- Calls YouTube Data API to schedule upload (if video file available)
